## Evidence time boundaries

1. **Historical evidence** records a dated provider/run/SHA fact and never transfers to a newer commit.
2. **Current exact-SHA evidence** exists only when the required check-runs and schema-v2 artifact identify the exact `testedSha`; for pull requests, `headSha`, `baseSha`, and the tested merge SHA remain distinct.
3. **Dynamic remote evidence** must be queried from GitHub at verification time. A committed Markdown file cannot permanently assert that its own commit is green.

Historical live smoke is not current exact-SHA live smoke. A current real-provider PASS requires a fresh non-fallback call matrix for the candidate SHA and an environment-only credential source.
